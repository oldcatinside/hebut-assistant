# 宣讲会信息助手

用于整理 Excel 宣讲会名单的 Windows 桌面工具。按用户输入的姓名精确筛选，生成通知文字和接待清单，支持手动复制及 Excel 导出，不自动发送消息。

## 功能

- 读取 `.xls`、`.xlsx`、`.xlsm` 的多个工作表。
- 支持常见表头别名；无表头或识别不明确时，可手动指定列和数据范围。
- 接待清单包含日期、时间、教室、手机号、企业名称。
- 无有效手机号时，显示同一行识别到的备注或提示；不猜测缺失信息。
- 清单可按日期时间排序；异常记录保留并提示核对。

## 运行

建议 Windows 10/11 64 位、Python 3.12。首次使用在项目目录执行：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m app.main
```

选择自己的 Excel 文件，填写筛选姓名，点击“读取名单”。常用列为：姓名、公司名称、宣讲会时间、宣讲会地点、联系人、联系人电话。读取不成功时，使用“设置与导出”中的“列设置 / 原表预览”。加密或损坏的文件需先修复或另存。

## 打包

安装 Python 后双击 `build.bat`。脚本会创建环境、安装依赖并生成 `dist/宣讲会信息助手.exe`。安装依赖需要联网。

## 通知与地点

通用通知模板位于 `app/message_builder.py`，可按实际活动要求修改，保留 `{time}` 和 `{address}` 占位符。程序不预设任何单位的入场要求。

清单只将不带楼号或校区的教室代码转为小写；完整地点保留原文，避免混淆。

## 数据

本仓库不附带实际名单、个人设置、日志、截图或 EXE。默认筛选姓名为空，默认不记住文件路径。使用过程中设置与日志保存在当前用户的本机应用数据目录；名单在本地处理，原始文件不会被改写。

请勿将自己的名单、导出结果或个人配置提交到仓库。`.gitignore` 已排除常见数据文件；网页手动上传仍需自行检查所选文件。
